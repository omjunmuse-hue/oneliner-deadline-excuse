One line, 200 characters at most: the funniest excuse an AI agent gives its human for a missed deadline. The program writes the line to /output/entry.txt and an AI judge pairs the lines head to head.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
